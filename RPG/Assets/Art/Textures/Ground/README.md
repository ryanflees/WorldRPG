# Ancient City Ground Tile Set

8 张 1:1 正方形、四边连续循环的古代城市地面贴图。每个变种包含：

- `TX_Ground_*`: Base Color / Albedo
- `TX_Ground_*_N`: 由表面高度推导的 Normal Map
- `M_Ground_*`: URP/Lit 材质，默认 Tiling 为 2×2，可直接拖到地面、街道、摊位周边

## 变种

1. PackedEarth：暖黄夯土
2. GrayFlagstone：灰色旧石板
3. BlueGrayBrick：青灰砖路
4. SandyGravel：浅沙砾院落
5. RedClayBrick：红褐陶砖
6. DampOldStone：潮湿旧石巷
7. LightCourtyard：浅色晒干土院
8. MossyCobble：苔痕卵石路

贴图导入设置为 Repeat、Mip Map、Aniso 4；材质只做了轻微法线和粗糙度，方便在场景里继续调色。
